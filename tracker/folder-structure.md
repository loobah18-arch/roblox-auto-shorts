# Folder Structure

Create these folders before your first clip. Keep one campaign's assets isolated.

```
campaign/      ← per-campaign rule sheets ([CAMPAIGN NAME] — RULES.md)
source/        ← approved raw footage for each campaign
transcript/    ← approved transcripts you analyze with the Clip Finder
project/       ← working edit files (CapCut projects, drafts)
export/        ← finished, verified clips ready to post
links/         ← saved post URLs + submission evidence
```

Suggested layout per campaign:

```
campaign/
└── [CAMPAIGN NAME]/
    ├── RULES.md
    ├── source/
    ├── transcript/
    ├── project/
    ├── export/
    └── links/
```
