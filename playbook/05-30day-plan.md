# 05 — The 30-Day Starting Plan

| Week | Focus | Activity |
|------|-------|----------|
| **1** | **Learn** | Review 10 campaigns, score 3, join 1–2 with clear terms, create 5 clips, log every field. |
| **2** | **Prove a creative angle** | Make 10 more clips from the best source format. Test **one variable at a time**: hook, length, or context layer. |
| **3** | **Systemize** | Batch source scan → Claude shortlist → editing → review → posting → submission → logging on fixed days. |
| **4** | **Scale only facts** | Compare approval rate, qualified views, cap exposure, and editing time. Keep winners, cut time-wasters. |

## Closing Principle

> Don't ask *how to make more clips*. Ask: **which combination of campaign, source moment, hook, and value layer produces the most approved, qualified views per hour of work?**

That question turns clipping from noise into a repeatable operating system.
