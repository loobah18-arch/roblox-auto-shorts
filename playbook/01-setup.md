# 01 — Non-Negotiable Setup (Before You Start)

Do all of this **before** touching any asset or campaign.

## 1. Whop Account

- Create a Whop account.
- Complete **identity** and **payout** verification.

Without verification, you cannot join most campaigns or receive payouts.

## 2. Real Public Accounts

- Set up real public accounts on each platform you plan to use (TikTok, Instagram, YouTube).
- Use a **niche-consistent page** with a clear profile and honest account info.
- These are the accounts you post from and submit to campaigns.

## 3. Folder Structure

Create this structure before your first clip:

```
campaign/
source/
transcript/
project/
export/
links/
```

- `campaign/` — per-campaign rule sheets
- `source/` — the approved raw footage
- `transcript/` — approved transcripts you analyze
- `project/` — your working edit files
- `export/` — finished clips ready to post
- `links/` — saved post URLs / submission evidence

## 4. Tracker From Day One

Use a tracker from the start (template in `../tracker/tracker.csv`) with at minimum:

- source timestamp
- version
- post URL
- approval status
- views
- payout cap

> "Never trust memory when you have 30+ posts live."

## 5. Read Campaign Rules First

Read the campaign rules **before downloading or editing any asset**. Every rule matters: platforms, lengths, hashtags, watermark, links, prohibited themes.
